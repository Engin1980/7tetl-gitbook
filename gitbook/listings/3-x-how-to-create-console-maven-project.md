# 3-x How to Create Console Maven Project

## What is Maven

Maven is a build automation and dependency management tool widely used in Java projects. It simplifies the development process by providing a standardized project structure, automated compilation, testing, packaging, and deployment. Instead of manually downloading and managing external libraries, developers declare project dependencies in the `pom.xml` configuration file, and Maven automatically downloads the required artifacts from remote repositories. In Spring Boot applications, Maven is commonly used to manage framework dependencies, execute tests, package applications into JAR files, and run various build-related tasks. By enforcing common conventions and automating repetitive activities, Maven improves project maintainability, consistency, and collaboration among development teams.

We will use Maven as a simple dependency manager. Using Maven configuration file, we will add to the project all required libraries.

{% hint style="info" %}
Without Maven, you need to add the libraries into the project on your own. This typically means download manually the appropriate `jar` file, put it into the correct folder and ensure that the project references the library.
{% endhint %}

## Maven project creation

Archetypes are predefined templates used to create and initialize the project into the basic state. For simple console application, we can use obsolete, but stil valid `quickstart` archetype.

To create a simple Maven project in IntelliJ IDEA using the Quickstart archetype, select **New Project** and choose **Maven** as the project type. Enable the option **Create from Archetype** and select the archetype **org.apache.maven.archetypes:maven-archetype-quickstart**. Next, specify the project coordinates, including the **GroupId** (typically representing the organization or package namespace) and **ArtifactId** (the project name). After confirming the settings, IntelliJ IDEA invokes Maven, generates the project structure, downloads the required dependencies, and opens the newly created project.

The generated project contains a standard Maven directory layout. Application source code is placed in the `src/main/java` directory, while unit tests are located in `src/test/java`. The project configuration is stored in the `pom.xml` file, which defines project metadata, dependencies, and build settings. The archetype also generates a simple Java class `App.java` with a `main` method and a corresponding unit test `AppTest.java`, providing a minimal starting point for further development.

A typical project structure generated by the Quickstart archetype looks as follows:

{% code lineNumbers="true" %}
```
my-project/
├── pom.xml
└── src
    ├── main
    │   └── java
    │       └── com
    │           └── example
    │               └── App.java   <-- here is the main() method
    └── test
        └── java
            └── com
                └── example
                    └── AppTest.java
```
{% endcode %}

The generated `App.java` file contains a minimal executable Java application:

{% code lineNumbers="true" %}
```
public class App {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```
{% endcode %}

Although the Quickstart archetype is primarily intended for standard Java applications, it remains a convenient way to create a minimal Maven project and understand the default Maven project structure before moving on to more complex frameworks such as Spring Boot.
